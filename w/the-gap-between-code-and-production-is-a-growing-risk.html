Why We Invested 2026-03-18

The gap between code and production is a growing risk

env zero and CloudQuery are merging to build what is defined as a Unified Cloud Intelligence platform.

As AI accelerates software development, more code is being pushed to production faster than existing systems were built to handle.

Customers need a system that connects what they intended to deploy with what’s actually running.

Joining forces is a major step in that direction. Especially as AI pushes more change into production than human-centric systems were built to control.

The gap between what’s defined in code and what actually runs in production is becoming a growing risk.

We’ve been with env zero since day one and are excited for what comes next. Looking forward to the next phase with Steve Corndell & Yevgeny Pats leading it forward.

Let’s build.
